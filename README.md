# George's Words releases

Downloads, the auto-update feed, and the website for **George's Words**,
a hold-to-dictate app for macOS (Apple Silicon) that keeps everything
on-device: no cloud transcription, no accounts, no telemetry.

- **Download:** grab `GeorgesWords.dmg` from the
  [latest release](https://github.com/zabugov/georges-words-releases/releases/latest),
  or use the [website](https://zabugov.github.io/georges-words-releases/).
- **Updates:** installed apps update themselves via
  [Sparkle](https://sparkle-project.org) from `appcast.xml` in this repo.
- **Problems?** [Open an issue](https://github.com/zabugov/georges-words-releases/issues).

This repo carries no application source code — only release artifacts.
Release binaries are built, signed, and notarized by the app's release
pipeline and published here.
